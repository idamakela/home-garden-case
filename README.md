# ItpHomeGarden

This repository uses an [Nx Monorepo](https://nx.dev/) setup, feel free to add you frontend inside this repository or create a separate repository.

More info:

- [docs/features.md](docs/features.md) — what the app can do, from a user and technical view
- [docs/tech-stack.md](docs/tech-stack.md) — stack and why
- [docs/work-log.md](docs/work-log.md) — minimal what changed and why related to my view of not specified in requirements but still required

## Prerequisites

You have Node.js installed on your machine and ran:

```sh
npm i
```

## Run backend

To run the backend, you can use this command

```sh
npm run api
```

Once it's running, you can check out the api specs at http://localhost:3000/docs

## Run frontend

To run the frontend, you can use this command

```sh
npm run web
```

Once it's running, the app is at http://localhost:4200
